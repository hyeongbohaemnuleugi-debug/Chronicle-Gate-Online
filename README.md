# Chronicle Gate v18 — 선택으로 이어지는 연대기

일곱 이야기를 짧은 장면과 실제 선택의 기록으로 읽는 1–4인 TRPG입니다. v18은 소개·본문·판정 결과의 문장을 다듬고, 장소를 옮기는 이유와 행동을 연결합니다. 관찰한 뒤에도 직전의 이동이나 전투 결과가 본문 앞에 남습니다. 각 이야기의 초반과 후반에는 혼자일 때와 여럿일 때 서로 다른 선택이 있습니다.

## 적용하기

- `FROM_v17_Changed_Files.zip`: 바로 전 v17 코드에 덮어쓰는 변경 파일 패치입니다. v17의 이미지·음원은 기존 경로에 있어야 합니다.
- `Cumulative_GitHub_PATCH.zip`: 사용자가 제공한 원본 프로젝트에서 바로 적용할 수 있는 누적 패치입니다. v17 적용 여부를 모르면 이 묶음을 사용합니다.

둘 중 맞는 **하나**를 풀어 기존 저장소의 같은 경로에 덮어씁니다. ZIP 자체를 업로드하거나 폴더를 한 겹 더 만들지 않습니다. `index.html`만 교체해서는 동작하지 않습니다.

```bash
npm ci
npm run verify
npm start
```

Node.js 22 또는 24에서 실행합니다. `/health`의 버전은 `18.0.0`입니다. 한 기기에서 먼저 플레이하려면 적용한 프로젝트에서 `node scripts/offline-server.mjs`를 실행하고 `http://127.0.0.1:4173/`을 엽니다.
