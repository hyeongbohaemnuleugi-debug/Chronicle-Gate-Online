# Chronicle Gate v24 — 이야기마다 다른 상대, 선택으로 남기는 결말

아홉 이야기를 짧은 장면과 실제 선택의 기록으로 읽는 1–4인 TRPG입니다. 이야기마다 네 직업이 있으며, 각자의 첫 장을 진행한 뒤 같은 장소에서 만납니다. 기본·서사시 모드, 네 판정 결과, 단서·물건, 전투·사망·부활과 여러 결말이 우리의 연대기에 남습니다.

v24에서는 **실제로 다른 상대 45종**을 만납니다. 기존 9종에 36종을 추가했고, 그중 9종은 경비원·징수꾼·고립 대원·기록 회수반처럼 이야기 속 목적을 가진 인간 인물과 집단입니다. 서로 다른 그림, 행동 예고, 협상 조건과 후속 문장을 갖습니다. 기본에는 이야기마다 3종, 서사시에는 5종이 배치되어 있으며 실제 전투는 선택에 따라 달라집니다. 모든 이야기에서 한 번도 싸우지 않고 일반 결말에 도달할 수 있습니다.

v23의 별도 전투 화면, 주사위 연출, 공격·방어·피격·대실패·사망·승패 효과음도 포함합니다. 기존 장면 삽화와 배경음·효과음은 그대로 보존했습니다.

## v22.1 또는 v23에서 적용하기

`Chronicle_Gate_v24_Enemies_Combined_PATCH.zip`은 **v22.1을 기준으로 추가·변경된 파일만 담은 누적 수정본**입니다. v23을 적용한 저장소에도 그대로 합칠 수 있습니다. 압축을 풀어 기존 저장소의 같은 경로에 덮어씁니다. 변경하지 않은 기존 파일도 계속 필요하므로 폴더 전체를 지우지 않습니다. 자세한 방법은 [v24 적용 안내](PATCH_NOTES_V24.md)에 있습니다.

```bash
npm ci
npm run build:offline
npm run test:all
npm start
```

Node.js 22 또는 24를 사용합니다. 화면 하단의 `STORY TABLE v24`, `/health`의 `24.0.0`으로 적용 여부를 확인할 수 있습니다. 운영 중인 서버는 파일 적용 후 재시작 또는 재배포합니다.

한 기기에서 인터넷 없이 플레이하려면 기존 `START_OFFLINE_WINDOWS.bat` 또는 `START_OFFLINE_MAC_LINUX.sh`를 실행하세요. 직접 실행하려면 `node scripts/offline-server.mjs` 후 `http://127.0.0.1:4173/`을 엽니다. 이 로컬 실행기는 Node.js만 필요하며 외부 인터넷이나 npm 의존성 설치를 요구하지 않습니다. `PLAY_OFFLINE.html` 더블클릭도 지원하지만, 음악의 정밀한 반복 재생에는 로컬 실행기를 권합니다.

저장 구조 22와 기존 핵심 전투 ID를 유지합니다. `chronicle-gate-v22`라는 저장 형식 이름은 호환을 위한 것입니다. 이미 지나간 장면에 새 상대가 소급해서 등장하지는 않으므로 추가 내용을 모두 보려면 새 이야기를 시작하세요. 진행 중인 기존 전투와 저장은 이어서 사용할 수 있습니다.

새 상대는 작성된 선택지와 판정으로 진행됩니다. 실행 중의 생성형 AI·이미지 생성·외부 음원 요청은 없습니다. `npm run report:resources`로 실제 파일 크기와 기존 자산 보존을, `npm run report:encounters`로 실제 완주 경로를 재검사할 수 있습니다. 이전 버전 번호가 붙은 문서와 보고서는 해당 릴리스의 기록이며, 최신 기준은 v24 문서입니다.
