Chronicle Gate v10.0.0 — Narrative Edition
패치 적용 안내
========================================

이 ZIP은 이미지·음원 전체를 다시 넣은 FULL 프로젝트가 아니라,
기존 Chronicle Gate 프로젝트에서 교체/추가해야 하는 파일만 담은 누적 패치입니다.
원본 프로젝트 또는 v9.x가 적용된 프로젝트 어느 쪽에도 덮어쓸 수 있도록 구성했습니다.

[적용 방법]
1. 기존 프로젝트를 한 번 백업합니다.
2. ZIP을 풉니다.
3. ZIP 안의 파일/폴더를 Chronicle Gate 프로젝트 최상위 폴더에 그대로 덮어씁니다.
   - campaign-data.js, server.js, package.json은 최상위에 위치해야 합니다.
   - public/* 는 기존 public 폴더에 덮어씁니다.
   - scripts/*, tests-release/*, supabase/migrations/* 는 같은 경로에 추가/교체합니다.
4. 배포 환경에서 다시 빌드/배포합니다.
5. 브라우저에서 Ctrl+Shift+R로 강력 새로고침합니다.

[Supabase]
- 이전에 v9.0.1 SQL HOTFIX를 성공적으로 실행했다면 SQL을 다시 실행할 필요가 없습니다.
- 아직 실행하지 않았다면 아래 파일을 Supabase SQL Editor에서 한 번 실행하세요.
  supabase/migrations/202609010002_accounts_and_progress.sql
- 이 파일은 기존 RPC 반환형 충돌을 피하기 위해 해당 함수만 DROP 후 재생성합니다.
  계정/엔딩 테이블의 사용자 데이터는 삭제하지 않습니다.

[v10 핵심 변경]
1. 이야기 중심 화면
   - '현재 상황 / 해야 할 일 / 당장 걸린 문제 / 눈앞에 보이는 것' 식 대시보드 제거
   - 장면 제목 → 작은 장소 표시 → 연속된 서술 → NPC 대사 → 선택의 흐름으로 변경
   - 중복 위치 캡션, 이벤트 덱 표시, 불필요한 영어 선택 헤더를 숨겨 이야기 집중도 향상

2. 선택지 ONLY
   - 직접 행동 입력창 제거
   - 서버도 자유입력 행동을 거부하여 화면과 실제 처리 규칙을 통일
   - 한 장면 3~5개의 의미 있는 선택지만 노출
   - 최종 결단은 주사위가 아니라 플레이어의 가치 선택으로 처리

3. 선택 결과가 다음 장면에 남음
   - 성공/실패 결과가 다음 장면 첫 문단에 자연스럽게 이어짐
   - 실패해도 이야기가 막히지 않고 대가·우회로·새 단서가 생기는 fail-forward 구조
   - 선택의 path/branch/flag/item 결과를 유지

4. 8개 범용 크로니클의 '공유 프롤로그'
   - 파티가 첫 장면부터 같은 실제 장소에 존재
   - 직업마다 같은 광경에서 서로 다른 이상 징후를 먼저 발견
   - 각 직업에는 첫 장면에서만 가능한 전용 행동 1개가 추가됨
   - 즉, 친구들과 같은 장면을 보면서도 '내 직업이라서 이게 보인다'는 역할감을 강화

5. '종착역 0번선' 수작업 미스터리 강화
   - 21개 수작업 장소/장면
   - 시설기사/역무원/보안요원/배달원/상담사/응급구조사별 서로 다른 시작
   - CCTV의 3분 17초 뒤 미래를 일부러 어긋나게 행동해 바꾸는 루트
   - 아직 잃어버리지 않은 물건이 분실물 보관함에 먼저 존재하는 사건
   - 아이템/정보 조건으로만 열리는 봉인 점검실·구형 신호 제어실
   - 일반 탈출 외 기록 보존, 0번선 봉쇄, 잔류/구조 계열 희귀 결말

6. 스토리 분량/연출
   - 9개 크로니클, 330개 핵심 장면
   - 각 핵심 장면 4~5개 서술 문단
   - NPC 대사와 감각적 단서, 즉시 압박, 장면별 구체 명사 중심으로 정리
   - 결말마다 3개의 서로 다른 가치 선택을 수작업 유지

7. 회원가입/로그인 규칙
   - 비밀번호 최소 4자, 최대 72자로 클라이언트/서버/HTML 통일
   - 예전 '8자 요구인데 4자까지만 입력' 같은 규칙 충돌 제거

[검증]
최종 패치는 원본 프로젝트 사본에 다시 덮어쓴 뒤 다음을 검사합니다.
- server.js / public/app.js / campaign-data.js 문법 검사
- scripts/qa.mjs Narrative QA
- tests-release/narrative-v10.test.mjs
- tests-release/release-v9.test.mjs

참고: tests/ 폴더의 오래된 테스트 일부는 과거 자유행동/과거 선택지 개수 자체를 정답으로 가정합니다.
v10 릴리스 판정은 tests-release/와 scripts/qa.mjs를 기준으로 합니다.

[실행]
npm install
npm start

[권장 Node.js]
Node.js 20~22
