# Chronicle Gate v21 — 선택 뒤에 이어지는 이야기

일곱 이야기를 짧은 장면과 실제 선택의 기록으로 읽는 1–4인 TRPG입니다. 이야기마다 네 직업이 있으며, 각자의 첫 장을 진행한 뒤 같은 장소에서 만납니다. 위험한 선택의 네 판정 결과, 전투·사망·부활과 여러 결말이 우리의 연대기에 남습니다.

v21은 각 이야기의 본편에 **장면 4개·일반 결말 2개·쓸 수 있는 물건 1개씩**을 더합니다. 본편 장면은 총 115개, 일반 결말은 총 35개입니다. 이야기별 전원 사망 결말 7개는 별도로 유지합니다. 새 갈래에서 누구의 뜻을 확인했는지, 무엇을 준비했는지에 따라 도착할 수 있는 결말이 달라집니다.

## v20에서 적용하기

`Chronicle_Gate_v21_FROM_v20_Changed_Files.zip`은 **v20 이후 추가·변경된 파일만** 담습니다. 압축을 풀어 기존 저장소의 같은 경로에 합칩니다. 기존 미디어 등 변경되지 않은 파일도 계속 필요합니다. 폴더 전체를 지우고 ZIP 내용만 넣지 마세요. 상세 절차는 [이번 수정 안내](PATCH_NOTES_V21.md)를 참고하세요.

```bash
npm ci
npm run build:offline
npm run test:all
npm start
```

Node.js 22 또는 24에서 실행합니다. 화면 하단의 `STORY TABLE v21`, `/health`의 `21.0.0`으로 적용 여부를 확인할 수 있습니다.

한 기기에서 인터넷 없이 플레이하려면 `START_OFFLINE_WINDOWS.bat` 또는 `START_OFFLINE_MAC_LINUX.sh`를 실행하세요. 직접 실행하려면 `node scripts/offline-server.mjs` 후 `http://127.0.0.1:4173/`을 엽니다. 이 로컬 실행기는 Node.js만 필요하며 외부 인터넷이나 npm 의존성 설치를 요구하지 않습니다.

기존 `PLAY_OFFLINE.html` 더블클릭도 지원합니다. 이때는 브라우저의 파일 접근 제약으로 별도의 음악 재생 경로를 사용하므로, 정밀한 반복 재생에는 위 로컬 실행기를 권합니다.
