# Chronicle Gate v18.1 — 문장과 인물 이름 읽기 개선

일곱 이야기를 짧은 장면과 실제 선택의 기록으로 읽는 1–4인 TRPG입니다. v18.1은 인물이 누구인지, 대사가 누구의 말인지, 낯선 설정이 왜 필요한지 쉽게 읽히도록 다듬은 수정판입니다. 게임 화면에서 등장인물 이름을 굵게 표시하며, 원문·저장 파일·연대기 TXT에는 HTML이나 볼드 기호를 넣지 않습니다.

## v18에서 적용하기

`Chronicle_Gate_v18_1_FROM_v18_Changed_Files.zip`은 v18 이후 추가·변경된 파일만 담습니다. 압축을 풀어 기존 저장소의 같은 경로에 덮어씁니다. `public/` 폴더를 기존 `public/` 안에 다시 만드는 방식으로 중첩하지 않습니다. 기존 그림과 음원은 유지합니다.

```bash
npm ci
npm run verify
npm start
```

Node.js 22 또는 24에서 실행합니다. 화면 하단의 `STORY TABLE v18.1`, `/health`의 `18.1.0`으로 적용 여부를 확인할 수 있습니다. 한 기기에서 먼저 플레이하려면 `node scripts/offline-server.mjs`를 실행하고 `http://127.0.0.1:4173/`을 엽니다.
