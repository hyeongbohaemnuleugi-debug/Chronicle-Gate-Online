Chronicle Gate v9.1.0 - CHOICE ONLY PATCH
=========================================

적용 대상
- Chronicle Gate v9.0.0 Living Story 패치를 적용한 프로젝트
- v9.0.1 SQL HOTFIX 적용 여부와 무관하게 이 패치를 적용할 수 있습니다.
- 이번 v9.1.0 패치는 Supabase SQL 변경이 없습니다.

적용 방법
1. 서버를 잠시 중지합니다.
2. 이 ZIP 안의 파일/폴더를 프로젝트 최상위 폴더에 그대로 덮어씁니다.
3. package.json도 함께 교체합니다. 의존성 버전은 바뀌지 않았습니다.
4. 서버를 다시 배포/재시작합니다.
5. 브라우저에서 Ctrl+Shift+R 강력 새로고침을 권장합니다.

핵심 변경
1) 자유행동 완전 비활성화
- 스토리 화면의 직접 행동 입력창을 완전히 숨깁니다.
- 일반 스토리/병렬 스토리 모두 선택지 버튼으로만 진행합니다.
- 구버전 클라이언트가 declaration을 전송해도 서버에서 선택지 전용 안내와 함께 거부합니다.

2) 현재 장면과 관계없는 선택지 제거
- 이전 장면 성공/실패에서 자동 생성하던 '앞선 선택의 여파' 행동을 새 장면 선택지에 더 이상 삽입하지 않습니다.
- 이전 선택의 결과는 스토리 서술, 상태, 위험도, 기억에는 계속 남습니다.
- 즉 '결과의 영향'은 유지하지만 새로운 장면의 버튼을 오염시키지 않습니다.

3) 선택지 장면 연관도 강화
- 현재 장면 자체에 작성된 선택지를 최우선합니다.
- 현재 상황, 현재 목표, 장면 본문과 직접 겹치는 행동을 높은 우선순위로 표시합니다.
- 조사/출처 찾기 장면에서는 조사, 확인, 추적, 촬영, 기록, 소리/신호 확인 행동을 우선합니다.
- 현재 장면에서 언급되지 않은 장소로 갑자기 돌아가거나 빠지는 이동 선택지는 일반적으로 숨깁니다.
- 비밀 루트, 핵심 아이템, 진엔딩 조건처럼 실제 게임 상태에 필요한 특수 선택지는 유지합니다.

4) 현재 위치 UI 축소
- 기존처럼 큰 카드 한 칸을 차지하지 않습니다.
- '현재 위치 · 장소명'을 작은 한 줄 스트립으로 바꿉니다.
- 상황/목표 두 칸은 그 아래에 배치하여 화면 세로 공간을 줄였습니다.
